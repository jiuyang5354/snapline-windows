本版新增
• 降低恢复历史图片和图片去重的内存开销：分块计算校验，不再额外申请整张图片的像素数组；保留原像素和原去重结果。
• 已在受限内存下复现并修复这项大图缓冲区申请失败；反馈用户那台电脑的启动报错仍需实际确认，本版不保证解决所有“内存不足”情况。

近期更新也已包含
• 调整设置窗口的绘制方式：背景扩散和光学贴图在打开时准备，拖动仅更新显卡采样坐标；实际拖动性能仍有待改善。
• 参考 Outpace 的边缘折射方式，将光学贴图交给原生像素着色器处理；中央保留毛玻璃扩散，深色背景自动使用浅色文字。
• 液态金属计算移到后台线程，减少悬停和点击时阻塞界面；保留独立亮边、外侧泛光和点击波纹。
• 扩大导航和开关，并修复只有文字或圆钮附近能触发的问题；整个按钮区域可点击，使用 Windows 原生开关和选择行为。
• 整窗毛玻璃进一步通透：降低白色覆盖，背景的山形、水面与文字层次更清楚，浅色和深色背景都保持可读。
• 液态金属按钮的边缘泛光增强：亮线更锐利，外侧冷白光晕更明显，悬停时泛光同步增强。
• 修复窗口四周出现一圈白色雾边的问题，玻璃边缘不再发灰。
• 修复按钮泛光被自身边界裁掉的问题，光晕完整延伸到胶囊外侧。
• 修复鼠标点击后多出一圈半透明焦点框的问题；键盘 Tab 导航仍保留清晰的焦点提示。
• 玻璃和金属效果使用原生 Windows 实现，参考提供的 liquid-glass 与 liquid-metal skill；无需浏览器运行组件。

• 自定义区域截图快捷键：默认 Ctrl + Alt + S，可在“设置 → 快捷键”单独录入，保存立即生效，重启后保留。
• 显示 / 隐藏和区域截图分别绑定；两组不能相同，按键被占用或保存失败时保留原设置。
• 更新公告：首次运行新版自动显示；托盘菜单和“设置 → 关于”可重看，离线可用。
• 修复部分 Windows 系统中，点击编辑无法打开画图的问题。
• 鼠标指向截图时，C 复制、A 编辑、D / Delete 取下；按住删除不会连续取下相邻图片。
• 修复长按编辑被图片缩放动画误判成拖动的问题。
• 新增区域截图：拖动框选，松开鼠标保存并复制，Esc 取消。
• 可选择在截图中包含鼠标指针，默认关闭。开启后先框选，再摆放指针，按 Enter 确认。

使用提醒
• 本版仍为预发布版，设置窗口拖动卡顿仍有反馈；读取原图仍需内存，启动报错如持续出现，仍需结合对方的实际数据和运行环境检查。
• 设置背景在打开窗口前采样并仅保存在内存；移动时从这份背景重新取样，背景中的视频和窗口变化不会实时刷新。
• 关闭 Windows 透明效果或使用高对比度时，材质回退为实色；关闭系统界面动画时，停止金属流动与点击动画。
• 单键快捷键会影响其他应用中的同名按键，建议使用组合键。Win + Shift + S 继续由 Windows 控制。
• 鼠标指针开关只影响 Snapline 自带的区域截图，不改变 Win + Shift + S。
• 覆盖安装保留原有截图、设置、快捷方式和开机启动状态。
