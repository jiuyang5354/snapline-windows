v1.5.1 Beta 2 · 静默收集与 WPS 兼容
• 设置 → 常规新增“收集新截图时自动展开”，默认开启。关闭后截图继续保存，但不主动弹出晾衣绳；顶部悬停、快捷键和托盘仍可展开。保存后立即生效，重启保留。
• WPS 来源增加兼容保护：除对象格式外，还会检查真正的剪贴板拥有者，跳过 WPS 演示、文字、表格发布的图片预览；不根据前台窗口判断，不影响截图工具和浏览器的图片。从 WPS 复制的普通图片也会跳过，请使用区域截图。
• 本机已验证 WPS 文本框、形状、整页和功能区复制的格式，但未复现反馈者的版本差异；兼容改动仍需现场复测。

v1.5.0 Beta 1 · 截图、暂存与离线文件工具
• PDF 工具箱、转格式、压缩、批量重命名和 ZIP 窗口统一为原生工作台，提供浅色 / 深色、矢量图标、短动效和主按钮局部柔光。外观与设置同步保存，颜色资源与截图玻璃分开。
• 工具之间可直接切换并携带当前文件；重命名后同步截图历史、暂存架和窗口列表，后续操作使用新路径。空工具窗口支持添加文件，ZIP 还可添加文件夹。
• 保留 v1.4.11 的 Office / WPS 剪贴板对象筛选：复制 PPT 文本框、形状或整对象时跳过其预览图，避免误收集。PPT / Word / Excel 中复制的图片对象也会跳过，需要时请用区域截图；浏览器复制图片和普通截图照常处理。
• 本版为小范围测试候选；文档转换、OCR 和签名尚未加入。旧版覆盖安装保留截图、设置和快捷方式，不会删除原文件。
• 优化 PDF / 转格式工具窗口：批量初始化勾选后统一刷新，避免每个文件反复校验整份列表；未变化的文件行不重复通知界面，转格式预览不再先重置再重画相同内容。减少文件较多时打开与切换工具的等待，保留原有界面和处理规则。
• 第一批离线 PDF / 图片工具：新增单图转 PDF、多图合并 PDF、WebP 有损 / 无损输出和静态 WebP 输入；图片和 PDF 均另存，原文件保留，同名自动编号。图片 PDF 不自动识别文字，动画和多帧图片不静默丢帧。
• 托盘与暂存架新增 PDF 工具箱：图片合成、PDF 合并、逐页拆分、提取 / 排列、删除页面、旋转、页码、中文矢量水印、AES-256 打开密码、填写原密码后移除保护。页序可用上移 / 下移及页码列表调整，后台处理可取消；合并失败不生成缺页结果。
• PDF 常用操作每次最多 512 页，合并最多 200 个文件 / 128 MB；表单与数字签名文档暂不处理。WebP 需要 64 位 Windows，转换组件随包携带，本地运行时不下载、不上传文档。Office、OCR、签名等按后续批次加入，具体范围见 PDF-TOOLS-PLAN.zh-CN.md。
• 顶部截图和右侧暂存架增加原生弹簧反馈：截图随鼠标和绳子受力倾斜，复制提示使用惯性轻摆；右侧卡叠、文件格轻微倾斜并在按压后回弹。反向输入保留当前位移与速度，静止、隐藏或移除时停止新增物理刷新，遵循 Windows 动画设置。玻璃材质、原文件与拖放规则保留。
• 截图栏不再只保留 12 张记录：每 9 张为一组，新增截图自动显示最新组，旧组隐藏保留，重启可恢复。滚轮向上查看旧图、向下查看新图，支持前后箭头和“最新”入口；窄屏可逐段翻看组内图片。隐藏图片释放缩略图缓存，清空会取下所有分组并保留原文件。此前已移出历史记录的收件夹图片不会自动重新挂入。
• 空暂存架默认隐藏到屏幕外，鼠标在主屏右侧边缘停留约 0.28 秒后滑出，移开约 0.42 秒后滑回；有文件时继续显示浮动卡叠。顶部角落、按住鼠标键和全屏场景不触发空架悬停唤出。
• 修复批量处理窗口收尾时再次显示已关闭暂存架的异常；手动打开暂存架后保持展开，直到鼠标进入后再移开。
• 暂存架改为右侧浮动卡叠，悬停或点击展开为两列文件网格；保留多文件叠、拆分、文字/链接/图片剪藏和拖出后保留偏好，不移动原文件。
• 展开使用可见的裁切边界，约 270 毫秒从卡叠展开到面板，文字随后淡入；约 180 毫秒反向收起。中途移回从当前进度继续；键盘、关闭系统动画和拖放时直接切换。
• 底部新增展开式批量工具栏，选择重命名、转格式、压缩或打包，再打开处理窗口。暂存架跟随已保存的浅色、深色或系统外观。
• 设置新增轻量控件动效：开关滑动、浅色 / 深色 / 系统选中底板滑动、侧栏选中移动、按钮轻微按压与内容短过渡。连续点击会转向最新状态，空闲停止；键盘操作、关闭系统动画或高对比度时直接切换，不增加保存等待。
• 设置改为实色界面，提供浅色、深色、跟随系统三段切换；保留六页设置与原生控件，移除设置窗口的桌面采样、整窗模糊与金属纹理计算。截图容器继续保留原玻璃效果。
• 新增清空截图栏快捷键，默认 Ctrl + Alt + Backspace，可在“快捷键”页自定义；截图栏工具条和托盘也可一键清空，只取下卡片，保留全部原文件。
• 截图拖入接收图片的聊天框或文件夹改为复制，成功拖出后仍留在绳上。“拖到未接收区域时取下”默认开启，松开无人接收时只取下卡片，原文件保留，Esc 取消不取下；已有明确关闭的偏好仍保留。
• 绳子根据拖动方向与距离持续轻微受力，附近卡片随之联动；反向拖动连续过渡，松开后衰减回弹并停止刷新。两端固定，遵循 Windows 的界面动画设置。
• 新增批量重命名、图片转格式、图片压缩及 ZIP 打包。右键暂存项目/文件叠，或点击暂存架顶部“···”处理全部；窗口内可勾选范围。
• 重命名支持 {name} 原名称和 {n} 连续编号，保留扩展名，先预览再确认；不覆盖已有文件，成功后同步截图栏和暂存路径。仅支持文件重命名。
• 图片可另存 PNG、JPEG、BMP、TIFF；压缩支持 JPEG 质量与长边限制，PNG 保留透明、JPEG 透明处填白。动画/多页与超大图跳过，不保留原元数据，结果不保证比原图小。ZIP 支持文件和文件夹；导出结果另存，不覆盖原件，后台处理可取消。
• 新增右侧文件暂存架：从桌面或资源管理器拖动文件时展开，也可用 Ctrl + Alt + D、托盘或设置打开。启用“在任何应用中拖动时都展开”后，可接收其他应用的拖动；自动展开复用现有输入轮询。
• 文件和文件夹只记录路径，不复制或搬迁原件；一次放入的多个文件合成一叠，右键可拆分。双击打开，右键可显示位置、复制路径或移出记录。
• 拖入文字、HTTP / HTTPS 链接和图片可保存为 TXT、URL、PNG 剪藏。多文件可一起拖出，取消拖动会保留记录；可设置成功拖出后仍保留。
• 暂存架记录、剪藏文件和开关随重启保留，存放在 Snapline 数据目录的 FileShelf 子目录。清空或移出暂存架不删除原文件与剪藏文件；暂停截图自动收集不影响主动拖放。

v1.4.10 已包含
• 自动收集先通过 Windows 原生接口检查格式，再读取图片；识别到文字、表格或已知 Illustrator / AICB / PDF / SVG 标记时直接跳过，不获取这些内容的 OLE 数据对象。
• 读取普通图片时复用已检查的格式列表，不再调用反馈中出错的 OLE 格式枚举接口；保留正常 PNG、位图和附带 HTML 图片的收集能力。
• 自动收集失败的警告每次运行最多提示一次，避免连续复制时反复打扰；后续失败仍更新本地 clipboard-error.log。正常跳过混合内容不提示。
• v1.4.9 的异常保护已获反馈者确认生效。本版进一步优化筛选路径；真实 Illustrator / WPS 的新路径仍需反馈者验证，不保证消除所有第三方剪贴板异常。

v1.4.9 已包含
• 自动收集前先识别格式，跳过带文字、表格、富文本或已识别的 Illustrator / AICB / PDF / SVG 矢量内容，不主动把这些混合内容当作图片读取。普通 PNG、位图及图片附带的 HTML 仍可收集。
• 位图透明通道检查改为分块读取，不再额外申请整张图片的像素数组；保留原有透明度和旧式零透明通道位图修复。
• 剪贴板图片读取、解码或保存发生内存/尺寸溢出异常时，跳过本次收集且不反复重试，保留下一次收集能力；本地 clipboard-error.log 记录原因，不自动上传。
• 已通过合成输入与受限内存测试；反馈者 Illustrator 2026 的实际崩溃仍需现场确认，本版不声称已解决所有相关崩溃。

v1.4.8 已包含
• 存储设置新增“更改位置”，可自选截图收件夹；保存后新截图写入新位置，旧图片不搬迁，旧自定义文件夹中的图片取下时保留原文件。
• 历史图片去重改用流式解码读取，不再缓存整张解码后的原图；保留原有像素校验结果。
• 长图缩略图按较长的一边限制为最多 480 像素，避免纵向长截图产生巨大的缩略图缓存。
• 新增本地 diagnostics.log，记录程序版本、启动阶段、内存状态和异常堆栈；区分启动失败与运行期间的报错。日志不含截图内容，不自动上传。
• 已通过生成图片的受限内存回归；反馈用户的实际报错仍需在对方电脑上确认。

v1.4.7 已包含
• 降低恢复历史图片和图片去重的内存开销：分块计算校验，不再额外申请整张图片的像素数组；保留原像素和原去重结果。
• 已在受限内存下复现并修复这项大图缓冲区申请失败；反馈用户那台电脑的启动报错仍需实际确认，本版不保证解决所有“内存不足”情况。

• 整窗毛玻璃进一步通透：降低白色覆盖，背景的山形、水面与文字层次更清楚，浅色和深色背景都保持可读。
• 液态金属按钮的边缘泛光增强：亮线更锐利，外侧冷白光晕更明显，悬停时泛光同步增强。

• 玻璃和金属效果使用原生 Windows 实现，参考提供的 liquid-glass 与 liquid-metal skill；无需浏览器运行组件。

• 鼠标指向截图时，C 复制、A 编辑、D / Delete 取下；按住删除不会连续取下相邻图片。
• 修复长按编辑被图片缩放动画误判成拖动的问题。
• 新增区域截图：拖动框选，松开鼠标保存并复制，Esc 取消。
• 可选择在截图中包含鼠标指针，默认关闭。开启后先框选，再摆放指针，按 Enter 确认。

使用提醒
• 本版仍为预发布版，设置窗口拖动卡顿仍有反馈；读取原图仍需内存，启动报错如持续出现，仍需结合对方的实际数据和运行环境检查。
• 设置背景在打开窗口前采样并仅保存在内存；移动时从这份背景重新取样，背景中的视频和窗口变化不会实时刷新。
• 关闭 Windows 透明效果或使用高对比度时，材质回退为实色；关闭系统界面动画时，停止金属流动与点击动画。
• 单键快捷键会影响其他应用中的同名按键，建议使用组合键。Win + Shift + S 继续由 Windows 控制。
• 鼠标指针开关只影响 Snapline 自带的区域截图，不改变 Win + Shift + S。
• 覆盖安装保留原有截图、设置、快捷方式和开机启动状态。
