## 运行

本地开发预览 `v1.5.0-preview` 新增文件拖拽暂存架、批量文件工具、实色深浅设置和拖拽优化，尚未发布到 GitHub；已发布版本仍以仓库下载链接为准。独立预览与安装版分别使用各自数据目录。

支持 Windows 10 / 11，需 .NET Framework 4.8 或更高版本（多数系统已经自带）。解压整个便携包，双击 `Snapline.exe`。无须安装 Python、Node.js 或 Swift，也不需要管理员权限。

当前版本为 v1.4.10 Windows 预发布版，先通过 Windows 原生接口筛选剪贴板格式，再读取普通图片，避开反馈中出错的 OLE 格式枚举路径；自动收集失败每次运行最多提醒一次，后续错误仍更新日志。保留历史图片恢复、去重与位图处理的内存优化。反馈者已确认 v1.4.9 的异常保护生效，本次新路径仍待 Illustrator / WPS 现场复测。软件内公告同步说明改动及验证边界。保留毛玻璃设置、液态金属控件、自定义区域截图键（默认 `Ctrl + Alt + S`）、画图启动修复、悬停操作及鼠标指针开关；设置拖动卡顿仍有反馈。安装版的程序内更新选择 EXE，校验后可点击“安装更新”覆盖升级。程序未作代码签名，Windows 可能提示未知发布者。源码和编译脚本已公开；实际验证范围见随包 `QA.md`。

程序驻留系统托盘；图标可能位于任务栏右侧的“隐藏图标”菜单。点击托盘图标或按 `Ctrl + Alt + T` 展开，再次点击或按快捷键收起。重复启动同一程序会唤起现有实例。

如果 `Ctrl + Alt + T` 已被其他软件占用，自动改用 `Ctrl + Alt + Shift + T`，并在托盘菜单和启动提示中显示。两个组合键都被占用时，仍可用托盘图标与顶部悬停操作。

## 新版界面

旧版细晾衣绳和银色金属夹子重新展示按原比例显示的截图。每张截图有独立的液态玻璃容器，边缘折射、高光与轻微色散跟随容器位置和变换；截图内容独立显示，不经过玻璃滤镜。去掉文件名和修改时间栏，保留悬停操作提示与取下按钮。

下方小工具条提供“区域截图”“复制最近一张”“暂停/恢复收集”“清空截图栏”“设置”，并显示当前收集状态与截图数量。图片和按钮接受鼠标输入，其他区域保持透明并穿透到桌面。

本地 v1.5 设置整合为常规、截图、快捷键、存储、暂存架、关于六页。设置开关与快捷键录入需保存后生效，取消保留原值；“全部取下”是立即执行的操作，会保留原文件。关闭设置不退出后台程序。

本地 v1.5 的设置采用实色背景，左下角“外观”可选择浅色、深色或跟随系统，点击“保存更改”后保留偏好。跟随系统时响应 Windows 应用主题变化，高对比度使用系统颜色。布局、三段切换、开关与字段提示参考 21st 的公开组件，以 WPF 原生实现；不引入浏览器或 React 依赖。设置不再采样桌面或生成玻璃 / 金属贴图；顶部截图容器继续使用原玻璃外框。

`Ctrl + Alt + Backspace` 一键清空截图栏，保留全部原文件；也可点击截图栏垃圾桶按钮或托盘“清空截图栏”。设置 → 快捷键可自行改键。截图拖入支持图片的聊天框或文件夹时复制，成功后仍保留卡片；目标软件必须支持接收图片 / 文件，管理员权限窗口仍受 Windows 拖放限制。

如果 QQ 等应用连资源管理器中的图片也拖不进去，请检查目标程序的“属性 → 兼容性”，取消“以管理员身份运行此程序”，退出后正常重启，再试拖入。普通权限程序不能向管理员权限程序拖放。QQ 9.9.28.46928 的现场对照已确认：取消管理员运行并重启后，当前图片与文件拖放格式可正常接收。

设置 → 截图 →“拖到未接收区域时取下”默认开启。将截图拖到截图栏以外无人接收的区域并松开，只取下卡片，原文件保留；Esc 取消与放回截图栏不会取下。已有明确关闭的偏好仍保留，可在设置中开启。某些应用拒绝图片时也会被视为未接收区域。绳子随拖动方向与距离轻微受力，附近卡片联动，松开后衰减回弹；静止后停止刷新，关闭 Windows 动画后保持静态。

开关滑动约 160 毫秒、主题选中底板约 180 毫秒、侧栏约 140 毫秒、按钮按压 / 恢复约 80 / 120 毫秒、内容短过渡约 120 毫秒。状态与点击立即生效，连续操作转向最新目标，动画结束释放时钟；首次打开不做入场，键盘操作不附加移动。Windows 关闭界面动画或启用高对比度时直接切换。动效参考 21st 的 Switch、Slide Tabs、Interfaces Button 与 Transition Panel，以原生 WPF 实现。

## 自定义快捷键

1. 右键系统托盘中的 Snapline 图标，选择“设置快捷键…”。
2. 点击“显示 / 隐藏截图栏”“区域截图”或“清空截图栏”的对应输入框，按下想绑定的单键或组合键，例如 `F8`、`Ctrl + Shift + Space`。
3. 点击“保存更改”，三组分别用于显示 / 隐藏晾衣绳、区域框选截图与清空截图栏，立即生效，重启后继续使用。录入后可再次点击输入框重新选择。

支持 Ctrl、Alt、Shift、Win 与一个普通按键的组合，也支持普通单键和功能键。修饰键须搭配其他按键；F12 是 Windows 保留键，不可绑定。单键会影响其他应用中的同名按键，字母或数字建议配合修饰键使用。

三组不能使用同一快捷键。如果组合已被占用或设置无法写入，会在设置窗口提示并保留原绑定。“取消”保留原设置；三行“恢复默认”分别选中 `Ctrl + Alt + T`、`Ctrl + Alt + S` 与 `Ctrl + Alt + Backspace`，再点击保存。录入时 Esc 恢复当前值，Tab 离开输入框。显示组合启动失败时尝试默认及备用组合；区域截图组合启动失败时提示重新设置，仍可用工具条或托盘截图。原先保存的偏好不会丢失；旧用户已经把显示键设为 `Ctrl + Alt + S` 时保留该显示键，需另选一个截图键。设置保存在同一数据目录的 `settings.json`；旧版本的图片列表与收集偏好可继续使用。

也可通过托盘“挂入图片…”加入已有图片，或“选择截图文件夹…”监听其他截图软件的新文件。默认监听 Windows 已登记的 Screenshots 文件夹；文件夹尚未创建时，程序等待它出现。支持 PNG、JPEG、BMP、GIF、TIFF；GIF 展示静态缩略图。

“收集剪贴板图片”会收集截图以及从其他应用复制的图片，无法保证只识别截图。可在托盘菜单关闭此项，只监听文件夹。文字剪贴板不会保存。

悬停按键仅在鼠标命中截图时触发；鼠标离开截图、截图栏收起或正在执行其他操作时保留普通输入。Ctrl / Alt / Shift / Win 组合仍交给原应用。悬停操作不会激活截图栏或抢走当前窗口焦点。

## 区域截图与鼠标指针

1. 点击工具条“区域截图”，或右键托盘选择“区域截图…”。
2. 拖动选择区域。默认松开鼠标即截图，保存到收件夹并复制。
3. 如需展示鼠标，打开 **设置 → 截图 → 截图包含鼠标指针**，开启后点击 **保存**。此开关默认关闭。
4. 开启后，先框选，再把鼠标放到需要的位置，按 **Enter** 完成；拖动可重新框选，**Esc** 取消。

框选使用开始截图时的桌面快照，背景在摆放指针时保持不动。只保存选定区域，取消不保存图片。暂停自动收集或关闭剪贴板收集时，主动区域截图仍可使用。这个开关仅用于 Snapline 自带截图；Windows 的 `Win + Shift + S` 和其他截图工具按各自设置工作。

## 更新与便捷操作

右键系统托盘中的 Snapline 图标：

- **自动检查更新（含预发布）**：默认开启，启动约 15 秒后检查；每 24 小时最多一次，同一版本只通知一次。取消勾选后停止后台检查，手动检查仍可使用。离线时静默失败，手动检查会显示原因。
- **检查更新… / 更新到新版本…**：查看版本与发布说明。安装版点击“下载安装包…”选择 EXE 保存位置，下载并通过 SHA-256 校验后，点击“安装更新”打开覆盖安装向导；启动前再次校验文件，等待用户确认安装。便携版点击“下载新版…”保存 ZIP，完成后在资源管理器中显示文件。下载可取消，失败或校验不通过会保留已有文件。
- **打开版本发布页**：在浏览器中查看 GitHub Releases，网络或通知有问题时也可手动下载。
- **暂停所有自动收集**：同时停止剪贴板与文件夹新图片收集，重启后保持暂停。已有图片仍可复制、预览，也可主动“挂入图片…”。取消勾选恢复后，跳过暂停期间的剪贴板图片和新文件。
- **复制最近一张**：直接复制当前列表最近一张，不需要先展开晾衣绳；成功后通知，没有图片时禁用。
- **开机启动**：默认关闭。勾选后为当前 Windows 用户登录时启动，不需要管理员权限；取消勾选移除注册项。程序换文件夹后请重新勾选，更新路径；Windows 设置或安全软件仍可能禁用启动项。

**升级到 v1.3.3：** v1.3.2 及更早版本的程序内更新仍只下载 ZIP，安装版请先从发布页下载新版 EXE，运行一次完成覆盖升级。之后安装版更新会选择 EXE，校验后点击“安装更新”，在向导中确认覆盖原目录。安装器正常退出该位置的旧程序后替换文件，截图、设置、开机启动项及已有快捷方式的 `--data-dir` 参数保留。便携版继续下载 ZIP，需要先从托盘退出再解压新版；没有安装登记时，安装包不会猜测便携版的位置。只有程序路径与安装登记一致才使用 EXE 更新，另一个目录中的便携副本保持 ZIP 更新。

## 文件拖拽暂存架（1.5.0 本地预览）

右键单个项目或一叠文件，可打开“批量重命名”“图片转格式”“图片压缩”“ZIP 打包”。暂存架顶部“···”对整个架操作；每个窗口都有勾选列表，可排除不处理的项目。

- **重命名**：仅处理文件；模板中 `{name}` 为不含扩展名的原名称，`{n}` 为连续编号，可设置起始值和补零位数。预览新旧名称后确认，更改的是原文件名；冲突不覆盖。文件名交换与仅大小写变化可处理；保存失败尝试恢复原名称。截图栏和所有暂存引用同步更新。
- **转换/压缩**：支持 PNG、JPEG、BMP、TIFF、静态 GIF 与静态 WebP 输入，输出 PNG/JPEG/BMP/TIFF、WebP（有损 / 无损）、单图 PDF 或合并多页 PDF。质量范围 1–100，默认 82；仅 JPEG / 有损 WebP 使用质量参数。长边默认 1920，转换页默认 0（保持尺寸），只缩小不放大。PNG / WebP 保留透明，JPEG 透明处填白；重新编码不保留原元数据。动画、多页及超限图片会跳过并说明原因；WebP 当前需要 64 位 Windows。
- **PDF 工具箱**：托盘或暂存架的 PDF 入口可打开。支持图片合成、合并 PDF、逐页拆分、提取 / 排列、删除页面、旋转、页码、中文文字水印、AES-256 打开密码和已知密码移除。左侧选工具、中间勾选并调整顺序、右侧设置参数。页码留空为全部，支持 `1-3,5`、`3,1,2` 和重复页码；图片转 PDF 也在转格式窗口提供。PDF 结果另存，合并遇到无效输入不会生成缺页结果。
- **处理范围**：图片 PDF 是图像页面，不含 OCR 文字层；页码和水印以矢量轮廓叠加。单图最多 3200 万像素 / 128 MB、输出长边最多 16384；PDF 最多 512 页，合并最多 200 个输入 / 128 MB。动画 / 多帧图片、交互表单与数字签名 PDF 暂不处理。组件随包携带，运行转换不联网；[后续工具规划](PDF-TOOLS-PLAN.zh-CN.md) 单独列出未实现功能。
- **ZIP**：支持文件、文件夹、空文件夹与中文名；同名顶层项目自动区分。输出不能位于待打包文件夹内，遇到符号链接/联接目录会停止并清理未完成输出，避免跟随到其他位置。提供取消。
- 图片和 ZIP 默认保存在数据目录 `FileShelf\Processed`，可另选位置；同名输出自动编号，原件保留，完成后结果加入暂存架。图片逐张处理，ZIP 流式写入；取消图片任务会保留已完成的结果。压缩后显示实际体积，不保证每次都更小。

- 从资源管理器或桌面开始拖动文件，主显示器右侧出现暂存架。默认只识别这些来源；设置 → 暂存架 →“在任何应用中拖动时都展开”可接收其他来源的拖动识别。该识别基于按下后移动的启发式判断，可能把框选等鼠标拖动也识别为展开请求；放入时仍检查真实拖放数据。
- `Ctrl + Alt + D` 或托盘 → 文件暂存架 → 打开 / 收起，可以随时打开。此键为固定入口；被其他应用或已配置的截图快捷键占用时保留原按键，使用托盘入口。设置中的快捷键录入不会误打开暂存架。
- 一次放入多个文件或文件夹会形成一叠；右键 → 拆开这一叠，可分成独立记录。只记录原位置，不复制、移动原文件；移出记录或清空不删除原文件。原件被移动、删除或暂时不可访问时，记录可能无法继续使用；重启会清理不可用路径。
- 从架子拖到文件夹、聊天软件或上传框，会提供真实的文件路径；不为图片额外加载完整位图。成功拖出默认移出记录，取消时保留；设置 → 暂存架 →“拖出后仍保留在暂存架”可更改。实际复制、移动或接受哪些文件，由目标应用决定。
- 图片、普通文字以及 HTTP / HTTPS 链接拖入后，保存为 PNG、TXT 或 URL 文件，位于当前 Snapline 数据目录下 `FileShelf\clippings`。不在放入时打开链接或执行文件；其他网址协议按普通文字保存。双击可打开文件，右键可显示位置、复制路径或移出记录。
- 暂存记录位于 `FileShelf\shelf.txt`，开关保存在 Snapline 的 `settings.json`。重启后恢复。暂停截图自动收集不影响主动拖放；在暂存架页关闭启用开关会隐藏它，保留已有记录。
- 共用 Snapline 的托盘与开机启动，无需同时运行 Dropline。已有 Dropline 暂存数据不自动导入或修改。来源与完整 MIT 许可见 `NOTICE.md`。
- 当前只停靠主屏右侧；管理员窗口与普通权限窗口之间受 Windows 拖放权限隔离限制。原生 WPF 测试窗口间的文件拖入拖出已经验证；真实资源管理器、浏览器和聊天客户端的完整兼容范围仍需实际试用。

源码可运行 `windows/build.ps1 -Shelf` 做合成数据、设置与原生快捷键检查，不接管键鼠或使用用户剪贴板。`windows/bin/Snapline.Tests.exe --shelf-drag 输出目录` 会实际移动鼠标并操作测试窗口，需要使用者先同意暂停键鼠操作；它仅使用生成文件，不修改原文件。

## 文件与行为

- 默认将收集的剪贴板图片保存至 `%LOCALAPPDATA%\Snapline\Inbox`。状态保存在同目录的 `settings.json`。
- 剪贴板自动收集先通过 Windows 原生接口检查格式，仅处理直接提供的 PNG 或位图；带有文字、表格、富文本或已识别的 Illustrator / AICB / PDF / SVG 矢量格式时直接跳过，不获取其 OLE 数据对象。普通图片附带的 HTML 可保留；混合内容若需保存为截图，可使用区域截图。读取图片复用已检查的格式列表，不调用 OLE 格式枚举。内存或尺寸异常只跳过本次；其他可恢复读取错误有限重试，仍失败时跳过。每次运行最多提示一次自动收集失败，后续错误仍更新数据目录的 `clipboard-error.log`，不自动上传。
- 设置 → 存储 → 截图收件夹 → 更改位置，可选择或新建文件夹，点击“保存”后生效；新截图写入新位置，旧图片保留原位置。重新选择默认收件夹即可恢复默认。当前收件夹和默认收件夹中的截图取下时进入回收站，旧自定义文件夹中的图片只取下卡片、保留文件。
- 更新检查只读取 `raw.githubusercontent.com` 上本仓库的 `update.json`；点击下载时访问 GitHub 及其发布文件 CDN。请求包含程序版本，不上传截图、剪贴板内容或本地路径，不需要账户，也没有遥测。关闭自动检查后，只有主动检查或下载才联网。图片仍可能通过聊天软件、Windows 剪贴板同步等功能离开本机，由对应程序管理。
- 截图按挂入顺序每 9 张一组，第 10 张开始新组并展示最新组；旧组的记录和原文件保留，重启恢复全部已记录分组。此前已被旧版移出记录的文件不会自动重新挂入，可手动导入。
- 在截图或分组条上滚轮向上查看旧图、向下查看新图，也可用分组条的前后箭头和“最新”。宽度足够时每组适配最多 9 张；窄屏显示组内范围并继续翻看，所有截图均可访问。新增截图返回最新组；删除后分组按剩余顺序重排。
- 仅当前显示的图片保留缩略图缓存，历史图片仍逐张校验；大量历史仍会增加重启读取时间。清空截图栏会取下全部分组，保留全部原文件；关闭程序不清空分组。
- 同一图片同时从剪贴板和文件夹出现时去重。程序自己复制图片不会反复新增。
- 不接管 Windows 截图快捷键，不修改截图工具的自动保存设置。截图工具仍可能保存自己的副本；可在截图工具设置里自行关闭自动保存。
- 检测到前台窗口的客户区覆盖整个显示器时收起，退出全屏后仍可从顶部或快捷键唤起。普通最大化窗口不会被当作全屏。
- 遵循 Windows 的界面动画设置。玻璃容器边缘使用展开前采样的桌面背景，样本只在内存中，收起后重新展开时刷新；视频或窗口内容变化不会逐帧更新边缘折射。系统关闭透明效果或启用高对比度时采用实色外框。
- 开机启动默认关闭，开启后在当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写入 `Snapline` 项；取消勾选移除。要退出程序，在托盘右键选择“退出”。

## 编译与验证

源码位于 `src/`，可用系统 .NET Framework 的 C# 编译器直接编译。使用 Windows PowerShell 或 PowerShell 7：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

如果系统没有 `Microsoft.NET\Framework\v4.0.30319\csc.exe`，安装 .NET Framework 4.8 Developer Pack 后再编译。测试使用 `qa/output/` 内的独立收件夹，测试过程临时使用系统剪贴板并恢复可读取的原格式。不要在同时进行复制操作时运行测试。

常规测试使用模拟 HTTP 响应，不依赖当前 GitHub 网络状态。发布版本文件后，可另行验证真实匿名联网与下载校验：

```powershell
.\bin\Snapline.Tests.exe --network .\qa\output\network
```

维护发布：运行 `package.ps1` 后会生成带 EXE 版本号的 ZIP、根目录 `SHA256SUMS.txt` 与 `dist/update.json`。先发布并核对 GitHub Release 的文件，再把 `dist/update.json` 复制到仓库根目录 `update.json` 并推送。发布正式版时需同步更改版本文件的 `prerelease` 标志。

也可指定独立数据目录用于便携运行或检查：

```powershell
.\bin\Snapline.exe --data-dir D:\SnaplineData
```

## 本地暂存架界面更新（2026-10-27）

空暂存架默认藏在屏幕外，鼠标在主屏右侧边缘停留约 280 毫秒后滑出，进入面板继续操作，移开约 420 毫秒后滑回。滑入约 320 毫秒、滑出约 220 毫秒；顶部角落留给截图栏，按住鼠标键或全屏时不触发悬停唤出。Ctrl+Alt+D 和托盘入口仍可打开空架，不写入示例文件。

有文件时，暂存架继续显示右侧浮动卡叠，悬停约 120 毫秒或点击展开两列文件网格。展开约 270 毫秒，外框从卡叠附近逐渐展开，文字随后显示；移开约 280 毫秒后，以约 180 毫秒收起。中途移回从当前边界继续。键盘、系统关闭动画或拖放时直接展开，避免接收区移动。动画结束停止时钟，空闲不持续刷新。

底部点击重命名、转格式、压缩或打包图标，再点“打开…”进入原有工具；右键单个项目仍可处理、拆分、显示原位置或移出。清空只移出记录，保留原文件。暂存架跟随设置保存的浅色、深色或系统外观。已有记录和拖出后保留偏好继续使用；空架通过 Ctrl+Alt+D、托盘或设置打开，不包含演示文件。右上角 × 只收起暂存架。
